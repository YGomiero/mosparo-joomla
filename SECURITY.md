# Security / Sécurité

For support, bug reports or suspected vulnerabilities, [open a GitHub issue](https://github.com/YGomiero/mosparo-joomla/issues/new). Include the extension, Joomla, PHP and mosparo versions, with a short description using fictitious data. Issues are public: do not post credentials, private keys, visitor data or details that would enable exploitation of an unpatched vulnerability. For a suspected vulnerability, start with a general description of the affected feature. Support is handled through GitHub Issues, not by email. The maintained release line is 1.1.x; update Joomla, PHP and mosparo independently.

Pour une demande d’assistance, un bug ou une vulnérabilité présumée, [ouvrez une Issue GitHub](https://github.com/YGomiero/mosparo-joomla/issues/new). Indiquez les versions de l’extension, de Joomla, de PHP et de mosparo, ainsi qu’une courte description avec des données fictives. Les Issues sont publiques : ne publiez ni identifiants, ni clés privées, ni données de visiteurs, ni détails permettant d’exploiter une vulnérabilité non corrigée. Pour une vulnérabilité présumée, commencez par une description générale de la fonction concernée. Le support se fait dans les Issues GitHub, pas par e-mail. La branche maintenue est 1.1.x ; Joomla, PHP et le serveur mosparo se mettent à jour séparément.

The integration fails closed when verification fails or the server is unavailable. Administrators must retain a recovery route before enabling login protection. Use HTTPS with certificate verification. The private API key stays server-side but is stored in Joomla plugin parameters: protect database backups and administrator access.

La vérification refuse une soumission en cas d’échec ou d’indisponibilité de mosparo. Prévoir une récupération avant d’activer la protection des connexions. Utiliser HTTPS avec vérification du certificat. La clé privée reste côté serveur mais figure dans les paramètres Joomla : protéger les sauvegardes et l’administration.

This package does not replace MFA, authentication throttling, Joomla updates or a security audit. Passkeys, remembered authentication, API login and third-party authentication routes are outside its login gate.
